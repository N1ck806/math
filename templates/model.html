Во всём проекте a — наклон, b — свободный член. Знак «крышка» (ŷ) означает предсказанное значение, а не измерение.

3. Система нормальных уравнений

Эта система получается приравниванием частных производных функции S(a, b) по a и по b к нулю. Она эквивалентна формулам наклона и свободного члена выше, но иногда удобнее для ручных вычислений на небольших наборах данных.

Зачем два вида формул

Формулы через центрированные данные удобны для вычислений на компьютере, система нормальных уравнений — для расчётов вручную и для понимания природы минимума.
